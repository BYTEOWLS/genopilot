# Sequencing read sets

Include all ten steps: contract inventory and approved decisions, versioned catalog/transition, import and editing, explicit workflow compatibility and selection, per-read-set preprocessing defaults, immutable snapshots/provenance, old-run handling, documentation, and verification.
