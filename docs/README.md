# GenoPilot documentation

The same pages are shown inside GenoPilot under Help.

- [Using GenoPilot](help.md): runs, catalogs, tooling, and keys.
- [Import review](import-review.md): importing isolates from a sequencing delivery.
- [Run results](run-results.md): the run metadata and files every result page shows.
- [Browser view](browser-view.md): local browser documentation, the genome development preview, themes, printing, and SSH forwarding.
- [Reading a genome view](genome-view.md): sequence coordinates, annotation tracks, and source/error states.

Each workflow documents itself in its own directory under [`workflows/`](../workflows/): its `README.md` explains the science, inputs, parameters, steps, outputs, and tools, and its `results.md` explains its result page. The repository [README](../README.md) lists the supported workflows, and covers installation and development.
